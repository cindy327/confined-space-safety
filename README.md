# KORAIL 밀폐 SAFE PASS - 생존확인 음성응답 추가본

## 변경사항
- 생존확인 알람에서 기존 `✅ 이상없음 · 터치 확인` 버튼 유지
- 지원 브라우저에서는 알람 중 `이상없음`이라고 말하면 진동·삐 소리 즉시 정지
- 생존확인 시작 시 마이크 권한을 한 번 요청해 알람 시 음성응답을 준비
- 마이크 권한 거부/음성인식 미지원 시 터치 버튼 방식으로 자동 대체
- 응답 로그에 `터치` 또는 `음성` 표시
- 새 탭에서 이전 알람이 자동 재생되지 않는 기존 오류방지 로직 유지

## 주의
브라우저 음성인식은 Chrome 등 지원 브라우저에서 동작합니다.
카카오톡 인앱 브라우저/일부 Samsung Internet 버전에서는 지원되지 않을 수 있으며,
이 경우 터치 확인 버튼을 사용합니다.

AI나 음성인식은 감시인 배치, 통신수단, 가스측정을 대신하지 않습니다.
